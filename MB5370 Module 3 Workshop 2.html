Mystery Repeat Region

Copied repeat sequence from Bandage into plain text file (called repeat.fasta) - annotated using prokka

prokka --outdir prokka --prefix repeat repeat.fasta

Examine the tsv file created

cat prokka/repeat.tsv

repeat.tsv shows the presence of key ribosomal RNA parts in bacteria (5S 23S and 16S ribsomal RNA), and then some other tRNA parts. This is consistent with our biological knowledge, as bacteria make lots of RNA and therefore require a lot of ribosomal repeats in the genome (which is what we can see in the repeat.tsv file!)

Genomic arrangement of repeats - we know repeats are present but we don’t know how they are arranged in the genome (are they in tandem or dispersed?)

ln -s ../quast/vibrio/vibrio.fna . #link in the data
minimap2 -x map-ont vibrio.fna repeat.fasta > repeat_vs_genome.paf #use minimap2 to map the DNA sequences

Used head to examine the repeat_vs_genome.paf file created by minimap2, then cat to extract columns into a bed formatted file

cat repeat_vs_genome.paf | grep '^repe' | awk -F '\t' '{print $6,$8,$9}' > repeat_locations.bed

The repeat is mostly tandem (repeat_locations.bed file shows 6 chromosomes, first coloumn is start position, second column is end position) - RNA is about ~5000bp which is fairly consistent with the start and end positions in the file. The indiscrepancies or outliers may be due to assembly problems, or specific biological reasons relating to bacterial ribosomal RNA (complicated…).
